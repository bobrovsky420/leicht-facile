# praemienverbilligung-brief.txt

## Was müssen Sie tun?

Sie haben am 1. Januar 2027 den Wohnort in Musterwil. \
Ihr Einkommen ist nicht höher als 42'000 Franken (lebt allein) \
oder 61'000 Franken (Verheiratet). \
Wenn Sie ein Kind haben, addieren Sie 9'000 Franken pro Kind.

## Was brauchen Sie?

- das Antrags·formular
- eine Kopie der Steuer·veranlagung
- eine Kopie der Kranken·versicherungs·police

Sie schicken das Formular bis zum 31. März 2027. \
Sie bezahlen keine Barauszahlung, das Amt zahlt direkt an die Krankenkasse. \
Ziehen Sie weg oder verdienen Sie mehr Geld. Melden Sie das in 30 Tagen. \
Wenn Sie nicht einverstanden sind, können Sie innerhalb von 30 Tagen Einsprache \
schreiben.

## Wann können Sie anrufen?

Rufen Sie die Sozial·versicherungs·stelle an: 044 123 45 67. \
Sie rufen von Montag bis Freitag von 8.30 bis 11.30 Uhr an. \
Sie rufen die Sozial·versicherungs·stelle an. \
Die E-Mail-Adresse ist ipv@musterwil.example.

## Wo finden Sie mehr Informationen?

Besuchen Sie www.musterwil.example/ipv.

## Wörterbuch

**massgebendes Einkommen**  
Das Einkommen, das das Amt für die Berechnung der Prämienverbilligung benutzt.

**Steuer·veranlagung**  
Die offizielle Bescheinigung vom Amt, die zeigt, wie viel Geld Sie verdient haben.

**Einsprache**  
Ein Brief an das Amt, wenn Sie mit einer Entscheidung nicht einverstanden sind.

**Krankenkasse**  
Die Krankenkasse bezahlt Kosten für Arzt
und Spital. Sie bezahlt auch Medikamente. Alle in der Schweiz müssen eine
Krankenkasse haben.
