Easy-language drafts of Swiss official texts

Leicht·Facile drafts easy-language versions of Swiss official texts (German Leichte Sprache and Einfache Sprache, French FALC, Italian lingua facile) with a large language model, and proves with code that no deadline, amount or phone number got lost. It is a drafting assistant for the people who write official texts, not a replacement for their review or for the test by readers from the target group.

How it works

The language model does everything that needs language understanding. Plain code does everything that can be counted.

  1. Understand (model)

    The document becomes a fact sheet: the reader's core questions, every fact with its exact value, hard words. Code adds every date, amount and contact the model missed.

  2. Write (model)

    A draft in easy language, every sentence linked to the source sentences it comes from, every omission explained.

  3. Check (code)

    Deterministic rules from the published Swiss guidelines and an exact check of every fact value in both directions: no value lost, no value invented.

  4. Judge (model)

    Meaning only: distorted facts, invented statements, metaphors, unclear references.

  5. Repair (model)

    Only the flagged sentences, until no blocking finding is left; then one sentence for each must-keep value still missing.

  6. Review (person)

    Source and draft side by side, provenance, fact checklist; approve, edit or reject each block, export with an audit trail.

Your model, your infrastructure

Leicht·Facile works with any OpenAI-compatible endpoint: a provider's API, a gateway or a model server of your own. Documents and review records stay in a database in a folder the organisation controls. At runtime the app contacts only the model endpoint, and a web page's server when a user enters a URL: no telemetry, no CDN, no login provider.

Why Apertus for confidential texts

A letter that names a person is under official secrecy, a patient letter under medical secrecy, a tax letter under tax secrecy. Such texts need a model that runs where the organisation controls it, with open weights and open training data, built in Switzerland. Apertus, by EPFL, ETH Zurich and CSCS, meets all of that, and Leicht·Facile was built and evaluated with it (why).

Get started

With uv installed, one command downloads the app from PyPI, starts it and opens the browser:

uvx leichtfacile serve

The app's model page asks for the endpoint and its key: Apertus on the CSCS inference API, the Public AI gateway, a provider such as Anthropic, OpenAI, Google or OpenRouter, or a server of your own (vLLM, llama.cpp, Ollama).
